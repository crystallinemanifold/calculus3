# Calculus III study guides

Open `index.html` for the study-guide homepage.

- `exam-1.html` — Chapters 2 and 3
- `exam-2.html` — Chapter 4
- `exam-3.html` — Chapter 5
- `final-exam.html` — Chapter 6, using the former Exam 4 material

All pages are standalone HTML with inline styles and controls. MathJax loads from a CDN; no build is required. Keep the shared `images/` directory beside these pages.

Source numbering is preserved, including entries intentionally marked omitted. See [SOURCE-NOTES.md](SOURCE-NOTES.md) for substantive corrections.
