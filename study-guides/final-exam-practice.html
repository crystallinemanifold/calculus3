Read each statement carefully. Circle every true statement and cross out every false one. A problem may have one true statement, several, or all five.

Mark every statement. A statement left unmarked counts as wrong.

Use ○ to circle and ✕ to cross out; click again to undo. The exam has six problems in 35 minutes, so aim for about six minutes per problem. Do a whole problem before checking it.

How to approach each statement

Treat every statement under a problem as its own small question, and do not decide it by how it looks. Each statement is settled by exactly one of four things:

  • Definition such as divergence, curl, a potential function, a scalar or vector line integral, or flux;
  • Theorem or property, such as the fundamental theorem for line integrals, Green’s theorem, Stokes’ theorem, the divergence theorem, or \(\operatorname{curl}(\nabla f)=\mathbf 0\);
  • Formula such as \(ds=\|\mathbf r'(t)\|\,dt\), \(dS=\|\mathbf r_u\times\mathbf r_v\|\,du\,dv\), or the area formula \(\frac12\oint x\,dy-y\,dx\);
  • Calculation to carry out: parametrize, substitute, take the dot product, integrate.

Before you circle or cross out, name which one applies, then use it. If it is a calculation, do the calculation.

Example. Problem 7(a) claims that the value of \(\int_C\nabla f\cdot d\mathbf r\) from \((1,1,0)\) to \((3,e,-1)\) depends on the path. That is a claim about a property of line integrals. The theorem that applies is the fundamental theorem for line integrals: for a gradient field, \(\int_C\nabla f\cdot d\mathbf r=f(\text{end})-f(\text{start})\) for every path. So the statement is false. The calculation gives the same number for every path: \(f(3,e,-1)-f(1,1,0)=-3\).

Every solution below is labeled with the definition, theorem, formula, or calculation that decides it.

Vector fields, divergence & curl

Problems 1–5
  1. 01

    Let \(\mathbf F=\langle x^3y,\ xz^2,\ y^2z\rangle\).

    1. (a)
      \(\operatorname{div}\mathbf F\) is a vector field.
    2. (b)
      \(\operatorname{curl}\mathbf F(1,1,1)=\langle0,0,2\rangle\).
    3. (c)
      \(\operatorname{div}(\operatorname{curl}\mathbf F)=0\).
    4. (d)
      \(\operatorname{div}\mathbf F=3x^2y+y^2\).
    5. (e)
      \(\operatorname{curl}\mathbf F=\langle2yz-2xz,\ 0,\ z^2-x^3\rangle\).
    Solution to problem 1

    Key: three statements are true.

    1. (a)

      (a) False. Definition divergence

      The divergence is a scalar function; the curl is the vector field.
    2. (b)

      (b) False. Calculation

      \(\langle2-2,\ 0,\ 1-1\rangle=\mathbf 0\).
    3. (c)

      (c) True. Theorem div curl = 0

      This holds for every \(C^2\) field. Check: \(\frac{\partial}{\partial x}(2yz-2xz)+0+\frac{\partial}{\partial z}(z^2-x^3)=-2z+2z\).
    4. (d)

      (d) True. Definition divergence

      \(\frac{\partial}{\partial x}(x^3y)+\frac{\partial}{\partial y}(xz^2)+\frac{\partial}{\partial z}(y^2z)=3x^2y+0+y^2\).
    5. (e)

      (e) True. Definition curl

      \(\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\rangle=\langle2yz-2xz,\ 0-0,\ z^2-x^3\rangle\).
  2. 02

    Each statement concerns the divergence or curl of a field.

    1. (a)
      If \(P\), \(Q\), \(R\) are differentiable functions of one variable, then \(\operatorname{curl}\langle P(x),Q(y),R(z)\rangle=\mathbf 0\).
    2. (b)
      \(\operatorname{div}\langle e^{x+y},e^{y+z},xyz\rangle=e^{x+y}+e^{y+z}+xy\).
    3. (c)
      \(\operatorname{curl}\langle e^{x+y},e^{y+z},xyz\rangle=\langle xz-e^{y+z},\ -yz,\ -e^{x+y}\rangle\).
    4. (d)
      \(\operatorname{curl}(y\mathbf i-z\mathbf k)=\langle0,0,1\rangle\).
    5. (e)
      \(\operatorname{div}(y\mathbf i-z\mathbf k)=-1\).
    Solution to problem 2

    Key: four statements are true.

    1. (a)

      (a) True. Definition curl

      Every entry of the curl is a cross partial such as \(\frac{\partial R(z)}{\partial y}\), which is \(0\).
    2. (b)

      (b) True. Definition divergence

      Differentiate each component in its own variable.
    3. (c)

      (c) True. Definition curl

      \(R_y-Q_z=xz-e^{y+z}\), \(P_z-R_x=0-yz\), \(Q_x-P_y=0-e^{x+y}\).
    4. (d)

      (d) False. Definition curl

      \(\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\rangle=\langle0,0,0-1\rangle=\langle0,0,-1\rangle\).
    5. (e)

      (e) True. Definition divergence

      \(0+0+\frac{\partial}{\partial z}(-z)\).
  3. 03

    Each statement claims an identity for every smooth \(f\) and \(\mathbf F\).

    1. (a)
      \(\operatorname{curl}(\nabla f)=\mathbf 0\).
    2. (b)
      \(\nabla(\operatorname{div}\mathbf F)=\mathbf 0\).
    3. (c)
      No nonzero field has both \(\operatorname{curl}\mathbf F=\mathbf 0\) and \(\operatorname{div}\mathbf F=0\).
    4. (d)
      \(\operatorname{div}(\operatorname{curl}\mathbf F)=0\).
    5. (e)
      \(\operatorname{div}(\nabla f)=0\).
    Solution to problem 3

    Key: two statements are true.

    1. (a)

      (a) True. Theorem curl grad = 0

      Each component is a difference of mixed partials, which are equal by Clairaut's theorem.
    2. (b)

      (b) False. Definition gradient and divergence

      For \(\mathbf F=\langle x^2,0,0\rangle\), \(\operatorname{div}\mathbf F=2x\) and \(\nabla(2x)=\langle2,0,0\rangle\).
    3. (c)

      (c) False. Calculation

      Any nonzero constant field, e.g. \(\langle1,0,0\rangle\), has both.
    4. (d)

      (d) True. Theorem div curl = 0

      Again the mixed partials cancel in pairs.
    5. (e)

      (e) False. Theorem curl grad = 0

      \(\operatorname{div}(\nabla f)=f_{xx}+f_{yy}+f_{zz}\); for \(f=x^2\) it is \(2\).
  4. 04

    The following statements concern pictures of vector fields.

    1. (a)
      For \(f(x,y)=x^2-y\), \(\nabla f=\langle2x,-1\rangle\).
    2. (b)
      \(\mathbf F=\langle x,y\rangle\) has divergence \(2\).
    3. (c)
      \(\mathbf F=\langle-y,x\rangle\) has divergence \(2\).
    4. (d)
      \(\mathbf F=\langle-y,x\rangle\) has scalar curl \(Q_x-P_y=2\).
    5. (e)
      The vectors of \(\mathbf F(x,y)=\langle y,1\rangle\) along the \(x\)-axis are horizontal.
    Solution to problem 4

    Key: three statements are true.

    1. (a)

      (a) True. Definition gradient field

      Partial derivatives \(f_x=2x\), \(f_y=-1\).
    2. (b)

      (b) True. Definition divergence

      \(1+1\): the field spreads outward from the origin.
    3. (c)

      (c) False. Definition divergence

      \(\frac{\partial(-y)}{\partial x}+\frac{\partial x}{\partial y}=0\). It rotates without spreading out.
    4. (d)

      (d) True. Definition curl

      \(1-(-1)=2\): a counterclockwise rotation.
    5. (e)

      (e) False. Calculation

      On the \(x\)-axis \(y=0\), so \(\mathbf F=\langle0,1\rangle\), which is vertical.
  5. 05

    The following statements concern the physical meaning of divergence and curl.

    1. (a)
      \(\mathbf F=\langle x,y,z\rangle\) has nonzero curl.
    2. (b)
      For \(\mathbf F=\langle x^2y,\ xy^2\rangle\), the scalar curl is zero only at the origin.
    3. (c)
      If \(\operatorname{div}\mathbf F(P)>0\), there is a net outflow from small regions around \(P\).
    4. (d)
      For a field on \(\mathbb R^3\), \(\operatorname{curl}\mathbf F\) is a scalar function.
    5. (e)
      The curl measures the rotation of a field; a tiny paddle wheel spins fastest when its axis lines up with \(\operatorname{curl}\mathbf F\).
    Solution to problem 5

    Key: two statements are true.

    1. (a)

      (a) False. Definition curl

      Each entry is a cross partial like \(\frac{\partial z}{\partial y}=0\); the curl is \(\mathbf 0\).
    2. (b)

      (b) False. Calculation

      \(Q_x-P_y=y^2-x^2\), which is zero on the whole lines \(y=x\) and \(y=-x\).
    3. (c)

      (c) True. Definition divergence

      Positive divergence means \(P\) acts as a source.
    4. (d)

      (d) False. Definition curl

      It is a vector field (only the divergence is a scalar).
    5. (e)

      (e) True. Definition curl

      The component of the curl along the axis is twice the paddle wheel's angular velocity.

Conservative fields & potentials

Problems 6–10
  1. 06

    Each statement claims whether a field is conservative.

    1. (a)
      \(\mathbf F=\langle\sin x,\ e^y,\ z\rangle\) is conservative with potential \(-\cos x+e^y+\frac{z^2}{2}\).
    2. (b)
      If \(\mathbf F\) is defined on all of \(\mathbb R^3\) and \(\operatorname{curl}\mathbf F=\mathbf 0\), then \(\mathbf F\) is conservative.
    3. (c)
      \(\mathbf F=\left\langle xyz,\ \frac12x^2z,\ 2z^2y\right\rangle\) is conservative.
    4. (d)
      \(\mathbf F=\langle x^2y,\ y^2x\rangle\) is not conservative.
    5. (e)
      \(\mathbf F=\left\langle\frac{y}{1+x^2},\ \tan^{-1}x,\ 2z\right\rangle\) has potential \(y\tan^{-1}x+z^2\).
    Solution to problem 6

    Key: four statements are true.

    1. (a)

      (a) True. Definition potential function

      Its gradient is \(\langle\sin x,e^y,z\rangle\).
    2. (b)

      (b) True. Theorem curl test

      \(\mathbb R^3\) is simply connected, so the curl test is conclusive.
    3. (c)

      (c) False. Theorem curl test

      \(R_y-Q_z=2z^2-\frac12x^2\neq0\), so \(\operatorname{curl}\mathbf F\neq\mathbf 0\).
    4. (d)

      (d) True. Theorem cross-partials test

      \(P_y=x^2\) but \(Q_x=y^2\); a conservative field needs \(P_y=Q_x\).
    5. (e)

      (e) True. Definition potential function

      \(\nabla\big(y\tan^{-1}x+z^2\big)=\left\langle\frac{y}{1+x^2},\tan^{-1}x,2z\right\rangle\).
  2. 07

    Let \(\mathbf F=\nabla f\), where \(f(x,y,z)=xyze^z\).

    1. (a)
      The value of \(\displaystyle\int_C\mathbf F\cdot d\mathbf r\) from \((1,1,0)\) to \((3,e,-1)\) depends on which path \(C\) is taken.
    2. (b)
      \(\oint_C\mathbf F\cdot d\mathbf r=0\) for every closed curve \(C\).
    3. (c)
      For any curve \(C\) from \((1,1,0)\) to \((3,e,-1)\), \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=-3\).
    4. (d)
      \(\mathbf F=\left\langle yze^z,\ xze^z,\ xye^z(1+z)\right\rangle\).
    5. (e)
      If \(C\) is the boundary of the unit square in the \(xy\)-plane, then \(\oint_C\mathbf F\cdot d\mathbf r=0\).
    Solution to problem 7

    Key: four statements are true.

    1. (a)

      (a) False. Theorem fundamental theorem for line integrals

      For a gradient field, \(\int_C\nabla f\cdot d\mathbf r=f(\text{end})-f(\text{start})\) for every path.
    2. (b)

      (b) True. Theorem fundamental theorem for line integrals

      A closed curve starts and ends at the same point.
    3. (c)

      (c) True. Theorem fundamental theorem for line integrals

      \(f(3,e,-1)-f(1,1,0)=3e(-1)e^{-1}-0=-3\).
    4. (d)

      (d) True. Definition gradient

      Differentiate \(f\); for \(f_z\) use the product rule on \(ze^z\).
    5. (e)

      (e) True. Theorem fundamental theorem for line integrals

      The curve is closed, so the start and end values of \(f\) agree.
  3. 08

    The following statements concern potentials and work.

    1. (a)
      The work required to move an object from \((1,1,1)\) to \((3,-4,-2)\) against that field is \(\frac{52}{29}\).
    2. (b)
      \(f=\dfrac{6}{x^2+y^2+z^2}\) is a potential for \(\mathbf F=-12r^{-4}\langle x,y,z\rangle\), where \(r=\sqrt{x^2+y^2+z^2}\).
    3. (c)
      For \(\mathbf F=\langle2xy,\ x^2+y^2\rangle\) along the quarter of the unit circle from \((1,0)\) to \((0,1)\), \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=\frac13\).
    4. (d)
      The work done against a force field \(\mathbf F\) along \(C\) equals \(\displaystyle\int_C\mathbf F\cdot d\mathbf r\).
    5. (e)
      \(\mathbf F=\langle2xy,\ x^2+3y^2\rangle\) has potential \(x^2y+3y^3\).
    Solution to problem 8

    Key: three statements are true.

    1. (a)

      (a) True. Theorem fundamental theorem for line integrals

      Work against \(\mathbf F\) is \(-\int\mathbf F\cdot d\mathbf r=f(P)-f(Q)=\frac63-\frac{6}{29}\).
    2. (b)

      (b) True. Definition potential function

      \(f=6r^{-2}\), and \(\nabla(r^{-2})=-2r^{-4}\langle x,y,z\rangle\).
    3. (c)

      (c) True. Theorem fundamental theorem for line integrals

      A potential is \(x^2y+\frac{y^3}{3}\); evaluate at the endpoints: \(\frac13-0\).
    4. (d)

      (d) False. Definition work

      That is the work done by the field. Work against it is the negative.
    5. (e)

      (e) False. Definition potential function

      \(\frac{\partial}{\partial y}\big(x^2y+3y^3\big)=x^2+9y^2\). A potential is \(x^2y+y^3\).
  4. 09

    The following statements concern tests for conservative fields in the plane.

    1. (a)
      A conservative field has exactly one potential function.
    2. (b)
      \(\mathbf F=\dfrac{\langle-y,x\rangle}{x^2+y^2}\) satisfies \(P_y=Q_x\), yet \(\oint\mathbf F\cdot d\mathbf r=2\pi\) around the unit circle.
    3. (c)
      For \(\mathbf F=\langle P,Q\rangle\) defined on all of \(\mathbb R^2\), \(\mathbf F\) is conservative exactly when \(P_y=Q_x\).
    4. (d)
      If \(\mathbf F\) is conservative, then \(\oint_C\mathbf F\cdot d\mathbf r=0\) for every closed curve \(C\).
    5. (e)
      \(\mathbf F=\left\langle9y-y^3,\ e^{\sqrt y}(x^2-3x)\right\rangle\) is conservative.
    Solution to problem 9

    Key: three statements are true.

    1. (a)

      (a) False. Definition potential function

      Adding any constant to a potential gives another one.
    2. (b)

      (b) True. Theorem cross-partials test

      Its domain has a hole at the origin, so equal cross partials do not guarantee a potential.
    3. (c)

      (c) True. Theorem cross-partials test

      \(\mathbb R^2\) is simply connected, so the cross-partials test is conclusive there.
    4. (d)

      (d) True. Theorem fundamental theorem for line integrals

      The line integral equals the change in the potential, which is zero around a loop.
    5. (e)

      (e) False. Theorem cross-partials test

      \(P_y=9-3y^2\) while \(Q_x=e^{\sqrt y}(2x-3)\); they are not equal.
  5. 10

    Let \(\mathbf F=\langle2x+y,\ x+2y\rangle\).

    1. (a)
      \(f(x,y)=x^2+xy+y^2\) is a potential for \(\mathbf F\).
    2. (b)
      \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=2\) for any path \(C\) from \((0,0)\) to \((1,1)\).
    3. (c)
      \(f(x,y)=x^2+y^2\) is a potential for \(\mathbf F\).
    4. (d)
      The scalar curl of \(\mathbf F\) is \(2\).
    5. (e)
      \(\mathbf F\) is not conservative because \(P\) depends on \(y\).
    Solution to problem 10

    Key: one statement is true.

    1. (a)

      (a) True. Definition potential function

      \(f_x=2x+y\) and \(f_y=x+2y\).
    2. (b)

      (b) False. Theorem fundamental theorem for line integrals

      \(f(1,1)-f(0,0)=1+1+1=3\).
    3. (c)

      (c) False. Definition potential function

      Its gradient is \(\langle2x,2y\rangle\), missing the \(xy\) cross term.
    4. (d)

      (d) False. Definition curl

      \(Q_x-P_y=1-1=0\).
    5. (e)

      (e) False. Theorem cross-partials test

      Conservativeness depends on \(P_y=Q_x\), which holds (\(1=1\)), not on which variables appear.

Scalar line integrals

Problems 11–14
  1. 11

    Let \(C\) be the segment \(\mathbf r(t)=\langle t,\ 2t-1\rangle\), \(0\le t\le1\), and \(f(x,y)=xy\).

    1. (a)
      \(\displaystyle\int_Cf\,ds=\frac{\sqrt5}{6}\).
    2. (b)
      \(ds=\sqrt5\,dt\).
    3. (c)
      \(\displaystyle\int_Cf\,ds=\int_0^1t(2t-1)\,dt\).
    4. (d)
      The scalar line integral \(\int_Cf\,ds\) changes sign when the orientation of \(C\) is reversed.
    5. (e)
      The length of \(C\) is \(\sqrt5\).
    Solution to problem 11

    Key: three statements are true.

    1. (a)

      (a) True. Calculation

      \(\displaystyle\int_0^1t(2t-1)\sqrt5\,dt=\sqrt5\left(\frac23-\frac12\right)\).
    2. (b)

      (b) True. Formula arc length element

      \(ds=\|\mathbf r'(t)\|\,dt=\|\langle1,2\rangle\|\,dt\).
    3. (c)

      (c) False. Formula arc length element

      The factor \(\|\mathbf r'(t)\|=\sqrt5\) is missing; this integral is \(\frac16\).
    4. (d)

      (d) False. Definition scalar line integral

      \(ds\) is always positive, so a scalar line integral does not depend on orientation. (Vector line integrals do change sign.)
    5. (e)

      (e) True. Formula arc length

      \(\int_0^1\sqrt5\,dt\).
  2. 12

    Each statement concerns a scalar line integral.

    1. (a)
      Over the helix \(\langle\cos t,\sin t,t\rangle\), \(-1\le t\le3\), \(\displaystyle\int_C(x+2y+z)\,ds=\sqrt2\left(\sin3+\sin1-2\cos3+2\cos1+4\right)\).
    2. (b)
      \(\int_C1\,ds=2\) over the upper unit semicircle.
    3. (c)
      Over the upper unit semicircle, \(\displaystyle\int_C(x-y)\,ds=-2\).
    4. (d)
      Over the upper unit semicircle, \(\displaystyle\int_Cx\,ds=0\).
    5. (e)
      The upper unit semicircle has length \(\pi\).
    Solution to problem 12

    Key: four statements are true.

    1. (a)

      (a) True. Calculation

      \(ds=\sqrt2\,dt\); \(\sqrt2\int_{-1}^3(\cos t+2\sin t+t)\,dt=\sqrt2\big[\sin t-2\cos t+\frac{t^2}{2}\big]_{-1}^3\).
    2. (b)

      (b) False. Formula arc length

      \(\int_C1\,ds\) is the length, \(\pi\).
    3. (c)

      (c) True. Calculation

      With \(\mathbf r=\langle\cos t,\sin t\rangle\), \(0\le t\le\pi\), \(ds=dt\): \(\int_0^\pi(\cos t-\sin t)\,dt=0-2\).
    4. (d)

      (d) True. Theorem symmetry

      The semicircle is symmetric about the \(y\)-axis and \(x\) is odd.
    5. (e)

      (e) True. Formula arc length

      \(\int_0^\pi\|\langle-\sin t,\cos t\rangle\|\,dt=\pi\).
  3. 13

    An L-shaped rod consists of the segments \(\langle2t,2\rangle\) and \(\langle2,2-2t\rangle\), \(0\le t\le1\), with mass density \(\rho(x,y)=x^2y\).

    1. (a)
      The mass of a wire \(C\) with density \(\rho\) is \(\int_C\rho\,ds\).
    2. (b)
      The first segment has mass \(\frac{16}{3}\).
    3. (c)
      The total mass is \(\frac{40}{3}\).
    4. (d)
      The mass equals \(\int_0^1\rho(\mathbf r(t))\,\|\mathbf r'(t)\|\,dt\) summed over the two segments.
    5. (e)
      The second segment has mass \(8\).
    Solution to problem 13

    Key: all five statements are true.

    1. (a)

      (a) True. Definition mass of a wire

      Sum density times length element.
    2. (b)

      (b) True. Calculation

      \(ds=2\,dt\) and \(\rho=4t^2\cdot2\): \(\int_0^116t^2\,dt\).
    3. (c)

      (c) True. Calculation

      \(\frac{16}{3}+8\).
    4. (d)

      (d) True. Formula arc length element

      \(ds=\|\mathbf r'(t)\|\,dt\) on each segment; here \(\|\mathbf r'\|=2\) on both.
    5. (e)

      (e) True. Formula arc length element

      \(\rho=4(2-2t)\) and \(ds=\|\langle0,-2\rangle\|\,dt=2\,dt\): \(\int_0^18(2-2t)\,dt=8\).
  4. 14

    Let \(\mathbf r(t)=\left\langle\ln t,\ \sqrt2\,t,\ \frac12t^2\right\rangle\), \(1\le t\le2\), and \(f(x,y,z)=e^x-\dfrac{y}{2\sqrt2\,z}\).

    1. (a)
      \(\displaystyle\int_Cf\,ds=\frac{11}{6}\).
    2. (b)
      \(f(\mathbf r(t))=t-\frac1t\).
    3. (c)
      \(\int_Cf\,ds\) is the same for every parametrization that traces \(C\) once.
    4. (d)
      The length of \(C\) is \(\frac32+\ln2\).
    5. (e)
      \(\|\mathbf r'(t)\|=t+\frac1t\).
    Solution to problem 14

    Key: all five statements are true.

    1. (a)

      (a) True. Calculation

      \(\int_1^2\left(t-\frac1t\right)\left(t+\frac1t\right)dt=\int_1^2\left(t^2-t^{-2}\right)dt=\left[\frac{t^3}{3}+\frac1t\right]_1^2\).
    2. (b)

      (b) True. Calculation

      \(e^{\ln t}=t\) and \(\frac{\sqrt2\,t}{2\sqrt2\cdot t^2/2}=\frac1t\).
    3. (c)

      (c) True. Theorem independence of parametrization

      Scalar line integrals depend only on the curve and \(f\).
    4. (d)

      (d) True. Formula arc length

      \(\int_1^2\left(t+\frac1t\right)dt\).
    5. (e)

      (e) True. Calculation

      \(\|\langle\frac1t,\sqrt2,t\rangle\|^2=\frac1{t^2}+2+t^2=\left(t+\frac1t\right)^2\).

Vector line integrals & work

Problems 15–19
  1. 15

    Let \(\mathbf F=\langle x^2,\ xy\rangle\) and let \(C\) be the parabola \(\mathbf r(t)=\langle t,t^2\rangle\), \(0\le t\le1\).

    1. (a)
      Along the straight segment from \((0,0)\) to \((1,1)\), \(\int\mathbf F\cdot d\mathbf r\) also equals \(\frac{11}{15}\).
    2. (b)
      \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=\frac{11}{15}\).
    3. (c)
      \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=\int_0^1\left(t^2+2t^4\right)dt\).
    4. (d)
      \(\mathbf F\) is conservative.
    5. (e)
      Traversing \(C\) from \((1,1)\) to \((0,0)\) gives \(-\frac{11}{15}\).
    Solution to problem 15

    Key: three statements are true.

    1. (a)

      (a) False. Calculation

      With \(\langle t,t\rangle\): \(\int_0^1(t^2+t^2)\,dt=\frac23\). Different paths give different values.
    2. (b)

      (b) True. Calculation

      \(\frac13+\frac25\).
    3. (c)

      (c) True. Formula vector line integral

      \(\mathbf F(\mathbf r(t))=\langle t^2,t^3\rangle\), \(\mathbf r'=\langle1,2t\rangle\).
    4. (d)

      (d) False. Theorem cross-partials test

      \(P_y=0\) but \(Q_x=y\). (The path dependence above also shows it.)
    5. (e)

      (e) True. Theorem orientation

      If \(D\) is a \(6\times10\) rectangle with a circular hole of radius \(2\), \(Q_x-P_y=-3\) on \(D\), and the inner circle \(C_2\) has \(\oint_{C_2}\mathbf F\cdot d\mathbf r=12\) (counterclockwise), then the outer boundary has \(\oint_{C_1}\mathbf F\cdot d\mathbf r=12\pi-168\).
    3. (c)
      If a rectangle \(R\) is split into triangles \(R_1\) and \(R_2\) with \(\oint_{\partial R}\mathbf F\cdot d\mathbf r=4\) and \(\oint_{\partial R_2}\mathbf F\cdot d\mathbf r=-2\) (all counterclockwise), then \(\oint_{\partial R_1}\mathbf F\cdot d\mathbf r=6\).
    4. (d)
      In the same situation, \(\oint_{\partial R}\mathbf F\cdot d\mathbf r=-4\) if \(\partial R\) is oriented clockwise.
    5. (e)
      In the same situation, \(\oint_{\partial R_1}\mathbf F\cdot d\mathbf r=2\).
    Solution to problem 31

    Key: three statements are true.

    1. (a)

      (a) False. Theorem Green’s theorem for regions with holes

      That ignores the inner boundary. The correct relation is \(\oint_{C_1}-\oint_{C_2}=-3(60-4\pi)\).
    2. (b)

      (b) True. Theorem Green’s theorem for regions with holes

      \(\oint_{C_1}-\oint_{C_2}=\iint_D(-3)\,dA=-3(60-4\pi)\), so \(\oint_{C_1}=12-180+12\pi\).
    3. (c)

      (c) True. Theorem additivity of circulation

      The shared edge is traversed in opposite directions, so \(\oint_{\partial R}=\oint_{\partial R_1}+\oint_{\partial R_2}\).
    4. (d)

      (d) True. Theorem orientation

      Reversing orientation negates the integral.
    5. (e)

      (e) False. Theorem additivity of circulation

      \(4=\oint_{\partial R_1}+(-2)\) gives \(6\).
  4. 32

    The following statements concern computing areas with line integrals.

    1. (a)
      Using \(x=a\cos t\), \(y=b\sin t\), the formula gives the area of an ellipse as \(\pi ab\).
    2. (b)
      The region between \(y=x^2\) and \(y=4\) has area \(\oint_Cx\,dy=\frac{32}{3}\).
    3. (c)
      For \(\mathbf r(t)=\langle t^2(1-t),\ t(t-1)^2\rangle\), \(0\le t\le1\), \(\frac12\oint(x\,dy-y\,dx)=\frac1{60}\).
    4. (d)
      For a counterclockwise boundary, \(\operatorname{Area}=\oint_Cy\,dx\).
    5. (e)
      For a counterclockwise boundary \(C\), \(\operatorname{Area}=\frac12\oint_C(x\,dy-y\,dx)\).
    Solution to problem 32

    Key: three statements are true.

    1. (a)

      (a) True. Calculation

      \(\frac12\int_0^{2\pi}(ab\cos^2t+ab\sin^2t)\,dt\).
    2. (b)

      (b) True. Formula area from a line integral

      \(\oint x\,dy\) gives the area for counterclockwise \(C\); the area is \(\int_{-2}^2(4-x^2)\,dx=\frac{32}{3}\).
    3. (c)

      (c) False. Theorem orientation

      The integral is \(-\frac1{60}\): the loop is traced clockwise. The enclosed area is \(\frac1{60}\).
    4. (d)

      (d) False. Formula area from a line integral

      \(\oint_Cy\,dx=\iint(0-1)\,dA=-\operatorname{Area}\); the formula is \(\operatorname{Area}=-\oint_Cy\,dx\).
    5. (e)

      (e) True. Formula area from a line integral

      Green's theorem with \(\mathbf F=\langle-\frac y2,\frac x2\rangle\), for which \(Q_x-P_y=1\).
  5. 33

    The following statements concern flux across a closed curve in the plane.

    1. (a)
      The outward flux of \(\langle x^3+2x,\ x^3+y\rangle\) across the circle \(x^2+y^2=4\) is \(24\pi\).
    2. (b)
      \(\langle-y,x\rangle\) has zero outward flux across every closed curve.
    3. (c)
      The outward flux of \(\langle x^3,\ yx^2\rangle\) across the boundary of the unit square is \(\frac43\).
    4. (d)
      \(\oint_{\partial D}\mathbf F\cdot\mathbf N\,ds=\iint_D\operatorname{div}\mathbf F\,dA\), where \(\mathbf N\) is the outward normal.
    5. (e)
      \(\oint_C\mathbf F\cdot\mathbf N\,ds=\oint_C\mathbf F\cdot d\mathbf r\) for every closed curve.
    Solution to problem 33

    Key: four statements are true.

    1. (a)

      (a) True. Theorem Green’s theorem (flux form)

      \(\operatorname{div}\mathbf F=3x^2+3\); \(\iint3x^2\,dA=3\cdot4\pi\) and \(\iint3\,dA=12\pi\).
    2. (b)

      (b) True. Theorem Green’s theorem (flux form)

      Its divergence is \(0\). (Its circulation, by contrast, is twice the enclosed area.)
    3. (c)

      (c) True. Theorem Green’s theorem (flux form)

      \(\operatorname{div}\mathbf F=3x^2+x^2=4x^2\); \(\int_0^1\!\!\int_0^14x^2\,dx\,dy\).
    4. (d)

      (d) True. Theorem Green’s theorem (flux form)

      This is the normal (flux) form of Green's theorem.
    5. (e)

      (e) False. Theorem Green’s theorem (flux form)

      The left side measures flow across \(C\) (divergence); the right side measures flow along \(C\) (curl). For \(\langle x,y\rangle\) on the unit circle they are \(2\pi\) and \(0\).
  6. 34

    The following statements concern fields with constant scalar curl.

    1. (a)
      \(\mathbf F=\left\langle-\frac y2,\frac x2\right\rangle\) has \(Q_x-P_y=1\).
    2. (b)
      \(\mathbf F=\langle x,0\rangle\) has \(Q_x-P_y=1\).
    3. (c)
      \(\mathbf F=\langle y,0\rangle\) has \(Q_x-P_y=1\).
    4. (d)
      If \(Q_x-P_y=1\), then \(\oint_C\mathbf F\cdot d\mathbf r\) equals the area enclosed by the counterclockwise curve \(C\).
    5. (e)
      The circulation of a conservative field around any closed curve is \(0\).
    Solution to problem 34

    Key: three statements are true.

    1. (a)

      (a) True. Calculation

      \(\frac12-\left(-\frac12\right)\).
    2. (b)

      (b) False. Calculation

      \(Q_x-P_y=0-0=0\). (\(\langle0,x\rangle\) works.)
    3. (c)

      (c) False. Calculation

      \(0-1=-1\).
    4. (d)

      (d) True. Theorem Green’s theorem

      Green's theorem gives \(\iint_D1\,dA\).

      Its line integral depends only on endpoints.

  1. 35

    Let \(\mathbf F=\langle3z,\ 5x,\ -2y\rangle\) and let \(S\) be the paraboloid \(z=x^2+y^2\), \(z\le4\), with upward normal.

    1. (a)
      \(\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S\) equals the flux of \(\operatorname{curl}\mathbf F\) through the disk \(x^2+y^2\le4\), \(z=4\), with downward normal.
    2. (b)
      \(\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=0\) because \(\operatorname{curl}\mathbf F\) is constant.
    3. (c)
      For Stokes' theorem the boundary circle must be oriented clockwise when viewed from above.
    4. (d)
      \(\operatorname{curl}\mathbf F=\langle-2,3,5\rangle\).
    5. (e)
      \(\displaystyle\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=20\pi\).
    Solution to problem 35

    Key: two statements are true.

    1. (a)

      (a) False. Theorem Stokes’ theorem

      The disk must have the same boundary orientation, which means an upward normal. With the upward normal the flux is \(5\cdot4\pi=20\pi\).
    2. (b)

      (b) False. Theorem Stokes’ theorem

      A constant nonzero curl still has nonzero flux through \(S\).
    3. (c)

      (c) False. Definition orientation of a boundary

      With an upward normal, the boundary runs counterclockwise when viewed from above (right-hand rule).
    4. (d)

      (d) True. Definition curl

      \(\langle R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\rangle=\langle-2-0,\ 3-0,\ 5-0\rangle\).
    5. (e)

      (e) True. Theorem Stokes’ theorem

      Around the boundary circle \(\langle2\cos t,2\sin t,4\rangle\): \(\int_0^{2\pi}(-24\sin t+20\cos^2t)\,dt=20\pi\).
  2. 36

    Let \(\mathbf F=\langle yz,\ xy,\ xz\rangle\) and let \(C\) be the square with vertices \((0,0,2)\), \((1,0,2)\), \((1,1,2)\), \((0,1,2)\), counterclockwise as viewed from above.

    1. (a)
      \(\oint_C\mathbf F\cdot d\mathbf r=-\frac32\).
    2. (b)
      \(\oint_C\mathbf F\cdot d\mathbf r=\iint_{[0,1]^2}(y-2)\,dA\).
    3. (c)
      \(\operatorname{curl}\mathbf F=\langle0,\ y-z,\ y-z\rangle\).
    4. (d)
      \(\oint_C\mathbf F\cdot d\mathbf r=\frac32\).
    5. (e)
      The normal to use for the flat square is \(\langle0,0,1\rangle\).
    Solution to problem 36

    Key: four statements are true.

    1. (a)

      (a) True. Theorem Stokes’ theorem

      Use the flat square at \(z=2\) with normal \(\mathbf k\): \(\iint(y-2)\,dA=\frac12-2\).
    2. (b)

      (b) True. Theorem Stokes’ theorem

      Only the \(\mathbf k\)-component of the curl, \(y-z=y-2\), contributes.
    3. (c)

      (c) True. Definition curl

      \(R_y-Q_z=0\), \(P_z-R_x=y-z\), \(Q_x-P_y=y-z\).
    4. (d)

      (d) False. Theorem Stokes’ theorem

      The value is \(-\frac32\).
    5. (e)

      (e) True. Definition orientation of a surface

      Counterclockwise from above goes with the upward normal (right-hand rule).
  3. 37

    The following statements concern Stokes’ theorem in general.

    1. (a)
      For a closed surface \(S\), \(\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=\iiint\operatorname{curl}\mathbf F\,dV\).
    2. (b)
      Two oriented surfaces with the same oriented boundary have the same value of \(\iint\operatorname{curl}\mathbf F\cdot d\mathbf S\).
    3. (c)
      If \(\mathbf F\) is conservative, then \(\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=0\) for every surface \(S\).
    4. (d)
      \(\oint_{\partial S}\mathbf F\cdot d\mathbf r=\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S\), with compatible orientations.
    5. (e)
      Stokes' theorem holds for either orientation of the boundary, regardless of the normal.
    Solution to problem 37

    Key: three statements are true.

    1. (a)

      (a) False. Theorem Stokes’ theorem

      \(\iiint\operatorname{curl}\mathbf F\,dV\) is not even a number. For a closed surface the flux of a curl is \(0\).
    2. (b)

      (b) True. Theorem Stokes’ theorem

      Both equal the line integral around the common boundary.
    3. (c)

      (c) True. Theorem curl grad = 0

      \(\operatorname{curl}(\nabla f)=\mathbf 0\).
    4. (d)

      (d) True. Theorem Stokes’ theorem

      This is Stokes' theorem.
    5. (e)

      (e) False. Definition orientation of a boundary

      The boundary orientation must match the normal by the right-hand rule; otherwise the sign is wrong.
  4. 38

    Let \(\mathbf F=\langle yz,0,x\rangle\) and let \(S\) be the part of the plane \(\frac x2+\frac y3+z=1\) with \(x,y,z\ge0\), with upward normal.

    1. (a)
      \(\displaystyle\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=-4\).
    2. (b)
      For Stokes' theorem the boundary is traversed \((0,3,0)\to(2,0,0)\to(0,0,1)\).
    3. (c)
      \(\displaystyle\iint_S\operatorname{curl}\mathbf F\cdot d\mathbf S=1\).
    4. (d)
      Writing \(S\) as \(z=1-\frac x2-\frac y3\), an upward normal is \(\left\langle-\frac12,-\frac13,1\right\rangle\).
    5. (e)
      \(\operatorname{curl}\mathbf F=\langle0,\ y-1,\ -z\rangle\).
    Solution to problem 38

    Key: one statement is true.

    1. (a)

      (a) False. Theorem Stokes’ theorem

      \(\operatorname{curl}\mathbf F\cdot\mathbf n=\frac{x}{2}+\frac{2y}{3}-\frac43\) over the triangle with vertices \((0,0),(2,0),(0,3)\) (area \(3\)). The constant term alone gives \(-4\); the other terms add \(1+2\), so the value is \(-1\).
    2. (b)

      (b) False. Definition orientation of a boundary

      That order is clockwise from above. The upward normal requires \((2,0,0)\to(0,3,0)\to(0,0,1)\).
    3. (c)

      (c) False. Theorem Stokes’ theorem

      The value is \(-1\).
    4. (d)

      (d) False. Formula normal to a graph

      An upward normal is \(\langle-z_x,-z_y,1\rangle=\left\langle\frac12,\frac13,1\right\rangle\), since \(z_x=-\frac12\) and \(z_y=-\frac13\).
    5. (e)

      (e) True. Definition curl

      \(R_y-Q_z=0\), \(P_z-R_x=y-1\), \(Q_x-P_y=-z\).
